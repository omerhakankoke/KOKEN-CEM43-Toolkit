# KOKEN CEM43 Araç Seti v1

Bu yazılım aracı, hipertermi tedavisi sırasında hedef dokudan elde edilen sıcaklık-zaman verilerini işleyerek birikimli termal dozu (CEM43) hesaplar.

Formül: Sapareto ve Dewey (1984). T < 43C için R=0.5; T >= 43C için R=0.25.

Kurulum gerekmez (salt Python 3). Denemek için: python cem43.py

Bu sistem, klinik süreçlerde tek başına tanı koyma veya tedavi kararı verme yetkisine sahip olmayıp, yalnızca hekim kararlarını destekleyen yardımcı bir veri sağlayıcıdır.

Lisans: MIT. Yazarlar: KÖKEN.
